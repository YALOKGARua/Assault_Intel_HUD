**Assault Intel HUD** (SuperBLT)

Standalone mini HUD showing assault/AI director telemetry:
- Phase: anticipation / build / sustain / fade
- Timers: phase end / dispatch / regroup (+ recon/reenforce when available)
- Pool: force pool / spawned / allowance (best-effort)
- Drama: amount + zone
- Counters: engaged / enemies
- Reasons: fade reason + assault end reason
- Phalanx state indicator

**Requirements**
- SuperBLT

**Install**
Put folder `Assault_Intel_HUD` into: `PAYDAY 2/mods/`

**Keybinds**
Options → SuperBLT → Keybinds
- Assault Intel: Toggle
- Assault Intel: Toggle Mode (compact/verbose)

**Notes**
Read-only telemetry. Some fields can show `n/a` depending on the current game state.
