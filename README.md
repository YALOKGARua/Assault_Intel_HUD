## Assault Intel HUD (SuperBLT)

### What this is
Standalone mini HUD that shows assault/AI director telemetry: phases (anticipation/build/sustain/fade), timers, pool/allowance, drama, engaged/enemies, and fade/end reasons.

### Requirements
- PAYDAY 2
- SuperBLT

### Install
Put the `Assault_Intel_HUD` folder into: `PAYDAY 2/mods/`

### Keybinds
Configure in: `Options → SuperBLT → Keybinds`
- `Assault Intel: Toggle` — show/hide HUD
- `Assault Intel: Toggle Mode` — compact/verbose

### Notes
Telemetry is read-only (no gameplay changes). Some timers can be `n/a` depending on the current director state.
